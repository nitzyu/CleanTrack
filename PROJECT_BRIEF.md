# ONE-PAGE PROJECT BRIEF
## CleanTrack: Barangay Waste Collection Tracker

**Project pitch**
CleanTrack gives residents a simple browser-based record for missed garbage collection. Users enter the area, date, and a short description, then review saved reports.

**Community problem**
Some households experience missed or delayed garbage collection. Residents might not keep a consistent record of collection concerns. A local digital log helps users record events for later reference. The specific situation in the target barangay should be confirmed through community observation or interviews.

**Target users**
Residents who want to record missed garbage collection using their own phone or computer.

**Proposed solution**
A responsive, single-page web app that stores missed-collection reports in the browser. The app provides a form, input validation, a saved report list, and a delete action.

**Main feature**
Create, view, and delete reports containing an area, date, and description.

**System architecture**
HTML builds the form and report list. Embedded CSS styles the interface. Vanilla JavaScript validates entries and updates the page. Browser localStorage saves the report array as JSON. No server or external database is used.

**Technologies**
HTML5, CSS3, JavaScript, localStorage, Git, and GitHub.

**Scope note**
CleanTrack is a local recordkeeping prototype. Reports do not automatically reach barangay officials or other residents.
